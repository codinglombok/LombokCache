# Vectors

`lombokcache-vectors-v1.json` is the cross-language test contract for LombokCache.

- SHA-256: `24e5dfcebc1aaab7021ceea1a0d73675cf1d7e1a0dd7b84fe591ab3b735e3601` (must equal the hash in `docs/SPEC_LombokCache_v0.1.0.md`).
- Generated by `scripts/gen-vectors.mjs`. Group `golden`: operation scripts whose per-step output is written by hand and matched against the TypeScript port during generation. Group `generated-regression`: seeded random scripts, with output from the TypeScript port confirmed by the Rust port.
- Every case calls the function `fn` with `args`; `expect` has the form `{ "result": ... }` or `{ "error": code }`.
- Every claimed port MUST run every case.
- Count: 142 cases (62 golden cases with hand-written expectations, 80 generated regression scripts; 1694 operation steps).
